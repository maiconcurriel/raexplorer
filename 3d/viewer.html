❓Central de Ajuda

🔍 Como navegar pelos Modelos

Utilize a barra de pesquisa no topo para buscar órgãos, sistemas ou peças específicas em tempo real.

🎛️ Filtros Avançados

Clique no botão Filtrar para abrir a listagem de categorias por Sistemas Anatômicos (Cardiovascular, Nervoso, etc.). Você pode selecionar múltiplos filtros ao mesmo tempo.

🖱️ Controles do Mouse no Cenário 3D

  • Botão Esquerdo (Arrastar): Rotaciona o modelo anatômico no espaço.
  • Botão Direito (Arrastar): Movimenta o modelo anatômico no espaço.
  • Scroll do Mouse (Roda): Aplica Zoom para aproximar ou afastar os detalhes.
  • Clique Esquerdo em uma peça: Destaca a sub-mesh e gera um balão de texto explicativo (Callout).

⚙️ Recursos de Operação

Modo Isolamento: Esconde as demais estruturas para você focar apenas no componente ativo.

Linha do Tempo (Animações): Use os botões inferiores para pausar, controlar a velocidade ou arrastar o progresso de modelos animados.

Acessibilidade: Use o seletor de daltonismo para alterar a matriz de cor e melhorar o contraste de veias, nervos e artérias.
